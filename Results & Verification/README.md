# Section C — Results and Verification

This directory contains aggregate result tables and selected verification records. The private source workbook is intentionally excluded.

## Result files

- `predictor_metrics_by_model.csv` — Brier score, log loss, mean prediction, observed rate, and calibration gap for the candidate law and comparator baselines.
- `outcomes_and_scores_by_model_structure.csv` — exact-success rates and proper scores by endpoint alias and graph structure.
- `calibration_by_operation.csv` — operation-level calibration estimates used by the candidate law.
- `composition_component_metrics.csv` and `composition_filter_node_metrics.csv` — strict component performance and aggregate FILTER_CHAR diagnostics.
- `task_cluster_bootstrap_brier_diff.csv` — archived task-family Brier-difference interval.
- `task_cluster_bootstrap_success_ci.csv` — supplementary task-family success-rate intervals; this archived table is not regenerated by the current aggregate-table builder.
- `calibration_only_baseline_metrics.csv` and `calibration_only_baseline_bootstrap.csv` — exploratory calibration-only comparator and uncertainty results.
- `embedded_json_metrics.csv` — post-hoc diagnostic; it does not replace strict exact success.
- `integrity_checks.json` — workbook/freeze checks generated from the private input. It records the workbook hash, not the workbook itself.
- `release_verification.json` — public-release scope and exclusions.
- `REPRODUCING.md` — exact run order, commands, and interpretation limits.

## Primary result

Across 192 composition predictions, the atom-product law had Brier score **0.134732**. The structure-specific baseline scored **0.123897**, the operation-count baseline **0.122706**, and the graph-corrected baseline **0.125725**. Lower is better. The atom-product law did not outperform these comparators in the pooled primary point estimates. The task-family bootstrap interval for the difference from the structure-specific baseline includes zero.

The pooled result does not establish that all multiplicative reliability models are invalid. The embedded-JSON recovery analysis is post hoc and is not the protocol's primary outcome.

## Reproduction and limitations

The aggregate tables can be inspected without the workbook. To regenerate them, use the private analyzed workbook with the commands in `REPRODUCING.md`. The public repository does not contain the workbook or raw model responses.

The selected prediction freeze has 192 rows and a SHA-256 sidecar. The primary script validates each frozen probability against a fresh calculation from the supplied calibration data, rather than checking Run_ID coverage alone. An alternate historical freeze must not be substituted.

Exact provider/version provenance is incomplete. The workbook lacks row-level run timestamps and exact-model-version metadata; a freeze hash does not independently establish chronology or preregistration. Calibration record `A0045` remains in the primary data, with its separate post-hoc sensitivity analysis clearly labelled.
