# Row-level audit scope

The public release does not include raw-response failure inventories, raw response excerpts, or detailed task-specific row-level score exports. These files are retained outside the repository because they duplicate response-level material and task-bank details.

Use the aggregate model-by-structure, predictor-comparison, calibration, and component tables in the parent directory for the public summary. The independent audit script can regenerate row-level checks from the researcher's private workbook.
